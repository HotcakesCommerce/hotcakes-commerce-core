プロジェクトの説明
==================
Hotcakes Commerceでは、チーム内の全員にとってエコマースが使いやすいものであるべきだと考えています。このオープンソースのエコマースソリューションは、その約束を実現します。

Hotcakes Commerceは、ストアオーナー、開発者、デザイナーの力を引き出す、企業向けのエコマースCMSです。簡単にストアを立ち上げたり、独自のシステムやサードパーティ製システムと連携したりできるほか、会社全体のオンラインプレゼンスの運営もサポートします。多くの方から「まるで箱の中に私の会社が入っているようだ」と評価されています。

強力なオープンソースのエコマースCMSであるだけでなく、Hotcakes Commerceには以下のような組み込み機能も備わっています：

* リッチテキストエディタ
* ファイル管理
* MS Azureとの互換性を持つクラウド対応
* モバイルAPIおよび基本的なモバイルデバイス検出機能
* C#で記述されたコア
* 1回のインストールで複数のポータル利用可能
* CSS 3、HTML 5、JQueryといった最新のクライアントサイドWebツール
* 高度なセキュリティ機能
* セキュリティロール、保護されたコンテンツ、サイトログといった管理機能
