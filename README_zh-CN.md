项目描述
==================
在 Hotcakes Commerce，我们坚信电子商务应该让团队中的每一个人都能轻松使用。这款开源电子商务解决方案正是为了实现这一承诺而打造。

Hotcakes Commerce 是一款专为企业设计的电子商务 CMS，能够为店铺所有者、开发人员和设计师提供强大支持。它让您能够轻松搭建店铺，将其与各种自定义系统及第三方系统集成，同时帮助您管理整个公司的在线业务。很多人称它为“装在盒子里的公司”。

除了是一款功能强大的开源电子商务 CMS 外，Hotcakes Commerce 还具备以下内置功能：

* 富文本编辑器
* 文件管理功能
* 具备 MS Azure 兼容性，可轻松接入云端
* 移动端 API 及基本的移动设备检测功能
* 用 C# 编写的核心代码
* 单次安装即可支持多个门户网站
* 支持 CSS 3、HTML 5 和 JQuery 等现代客户端 Web 工具
* 强大的安全性
* 管理功能，包括：安全角色设置、受保护内容管理以及站点日志记录
